First Wiki is a wiki written in Python. I write this because I counln't find a beautiful wiki in Python.


First Wiki is based on [shire](https://leons.im/posts/shire/), which is a web framework based on Tornado Web Server, MongoDB and Bootstrap.

First Wiki is open source, license is <https://github.com/leonsim/firstwiki/blob/master/LICENSE>. Source code is hosted on [GitHub](https://github.com/leonsim/firstwiki).

<!--more-->

## Features

- Version control
- Markdown rendering
- User authentication and authorization
- Beautiful
- Python based
- Open source

## Getting Started

```
git clone https://github.com/leonsim/firstwiki.git
cd firstwiki
pip install -r pip-req.txt
python scripts/init.py
python start.py
```

Open <http://127.0.0.1:8004>
Go hacking!

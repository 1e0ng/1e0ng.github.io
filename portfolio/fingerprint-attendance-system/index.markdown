This project was developed in 2009.
The system is for teachers to check on attendance of students by fingerprint.
Students should register their fingerprint into the system beforehand.
The system manipulates the fingerprint information of each student, and abstracts some eigenvalues for identification. Note this system uses _one to one_ comparison to identify fingerprint.
Later, the teacher can check on attendance by fingerprint.
The attendance record can be viewed through the website of the system.
